# Style notes

Read before writing every scenario. Your feedback and the reasons for rejected scenarios are appended here
automatically by the panel (General note, Reject).

## Fixed rules
- Tone: cheerful and warm, like telling a friend. Short sentences.
- Length is free: no fixed number of sentences or duration. A quick joke can be 2–3 sentences, a story or dialogue 8–10. Vary length, structure and opening; the first sentence is a hook (a question, a surprising moment, a funny reaction).
- Only features that really exist in the app (`studio/APP_FACTS.md`). No invented buttons or text.
- Last sentence and end card: app logo + where to get it (`brand.json` → `end_card`).
- Background music only from `assets/music`. Scenarios use `"music": "auto"`; the user can change it in the panel.
